# Adapter Manifests

This directory contains structured medium-specific manifests that point back to a character identity revision.

They are not character canon.

Current v0.1 examples use JSON for concrete machine-readable proof. The documentation may show YAML-like examples for readability; no project-wide serialization mandate has been made beyond the current proof.

A manifest should contain only information needed to trace and validate an adaptation. Large binary assets belong under the retained asset policy when they actually exist.
