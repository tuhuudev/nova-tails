# Character Data

Structured character identity instances live here when a real retained instance exists.

Lifecycle matters:
- DRAFT data may be used for experiments/proofs;
- APPROVED data is accepted current canon;
- LOCKED data carries stronger downstream dependency expectations.

A file existing in this directory does not automatically make its character canon. Consumers must inspect lifecycle and revision.

`NT-CHAR-001.json` is currently a DRAFT architecture reference only.
