# NT-CHAR-001 — Controlled 2D Adaptation Brief v0.1

**Status:** READY FOR ARTIFACT GENERATION

## Source

Character: `NT-CHAR-001@0.1`  
Lifecycle: DRAFT

## Objective

Create a neutral 2D design artifact that demonstrates whether the same identity contract can drive visual production without re-inventing the character.

## MUST PRESERVE

- floating, non-quadruped topology;
- central core as the visual focus;
- meaningful open negative space around the core;
- incomplete/asymmetric orbit rather than a complete halo;
- broken-orbit geometry must affect silhouette, not appear only as VFX decoration.

## MAY ADAPT

- exact orbit rotation;
- expression/core face treatment;
- surface detail density;
- lighting;
- restrained material/palette exploration;
- camera within a neutral 3/4 design presentation.

## MUST NOT INVENT AS CANON

- faction;
- element;
- combat powers/class/role;
- rarity;
- final name;
- lore;
- evolution stage.

## Presentation

Primary artifact:
- neutral background;
- full body visible;
- neutral 3/4 view;
- no environment or narrative scene;
- no labels required in the image;
- orbit gaps clearly readable at thumbnail scale.

Secondary proof later:
- visibly different pose/orbit rotation;
- same identity must remain recognizable.

## Review gate

PASS if a reviewer can identify the same central-core + broken-orbit identity without relying on color/name and no new anatomy contradicts the master contract.

REVISE if the result becomes a generic perfect-halo orb, an animal with decorative rings, or a VFX composition whose structural orbit disappears when effects are removed.
