# NT-CHAR-001 — Card/2D Adaptation Proof Brief

**Status:** PLANNED

## Purpose

Create a representative 2D visual that demonstrates expressive adaptation while preserving the same identity contract intended for print.

## Required read
- central core is primary mass;
- incomplete asymmetric orbit is immediately visible;
- orbit negative space remains legible at thumbnail scale;
- character reads as floating/non-grounded;
- orbit is body/signature structure, not merely environmental effect.

## Free variables
- camera angle;
- orbit phase within invariant limits;
- lighting;
- background;
- expression cues;
- surface-detail treatment;
- restrained palette exploration.

## Prohibited drift
- perfect symmetrical halo;
- normal animal body hidden inside effects;
- VFX that visually replaces the orbit;
- major new appendages/signatures treated as identity without upstream review.

## Validation

Review the final visual both at normal size and thumbnail/silhouette-like read. Record any identity information that had to be added manually outside the reviewed context; such additions indicate a missing L0/L1 contract requirement.
