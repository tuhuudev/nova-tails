# NOVA TAILS — Product Vision v0.1

**Status:** REVIEW  
**Date:** 2026-09-16  
**Purpose:** Decide what product is worth testing before deeper lore, taxonomy, combat, economy or asset production.

## 1. Problem this phase must solve

NOVA TAILS currently has several attractive ideas—original character universe, collection/progression game, 2D art, modular printable figures—but attractiveness is not product validation. The main risk is attempting to build all of them at once before proving which core value people actually care about.

This document therefore treats every product format as a hypothesis.

## 2. Current evidence snapshot

### Mobile/game market

Public 2025 market commentary shows continued activity around hybrid products that combine a simple/readable core with deeper meta systems, including character collection. This is evidence that hybrid structures exist and can perform; it is **not** evidence that NOVA TAILS should copy them or that a generic gacha/card battler has product-market fit.

A major implication for us: collection/progression can support a product, but it should not substitute for a distinctive core interaction/value proposition.

### Physical/3D ecosystem

MakerWorld currently supports creator commercial-license membership models and requires uploaded/licensed models to be original or properly authorized. This makes an original printable-character ecosystem a plausible distribution/business extension, but also raises the importance of provenance and rights review.

The Bambu Lab A1 mini has a 180 × 180 × 180 mm build volume. If A1-mini compatibility remains a target, physical designs must be validated against that real constraint rather than invented dimensions in concept documents.

## 3. Product hypotheses

### H1 — Game-first character universe

A character-collection game is the primary product; 2D/3D/content are extensions.

**Potential upside**
- gives characters functional meaning and progression;
- creates a repeatable digital loop;
- world/character assets can support long-term content.

**Major risks**
- highly competitive content/live-ops burden;
- generic auto-battler/gacha loop would provide weak differentiation;
- economy/retention complexity can consume development before core fun is proven.

**Status:** REVIEW — not accepted.

### H2 — Character/IP-first collectible ecosystem

The primary product is a recognizable original character universe. Digital experiences, cards, prints and content are different ways to encounter/collect the same identities.

**Potential upside**
- strongest alignment with existing visual/3D exploration;
- allows smaller experiments before a full game;
- reusable identity assets may compound across media.

**Major risks**
- an IP is not valuable merely because many characters can be generated;
- requires a strong visual/narrative hook and evidence that people care about the characters;
- monetization/distribution is less automatic than shipping a conventional game loop.

**Status:** REVIEW — currently the broadest strategic hypothesis worth testing.

### H3 — Printable-collectible-first

The first concrete product is modular, easy-to-print original character collectibles; game/lore grows later.

**Potential upside**
- narrow scope and tangible output;
- direct physical validation is possible;
- creator marketplaces provide distribution paths;
- no-AMS/color-separated modular design could become a useful design constraint.

**Major risks**
- 3D modeling/engineering remains real work even when concepts are AI-assisted;
- demand for original unknown characters must be proven;
- optimizing the entire IP around FDM too early could weaken digital/visual design.

**Status:** REVIEW — candidate early proof, not yet primary product.

### H4 — Content-first audience building

Short-form character/lore/design/printing content is used to discover which identities/themes generate interest before building a large product.

**Potential upside**
- comparatively cheap market signal;
- can test visual identity, character appeal and physical transformation;
- creates audience before large development cost.

**Major risks**
- social engagement does not automatically imply willingness to play/buy;
- optimization for algorithms can distort the underlying IP;
- content pipeline can become busywork without explicit experiments.

**Status:** REVIEW — useful validation channel, not automatically the product.

## 4. Working strategic direction

Do **not** commit yet to “mobile gacha game” as the product.

The strongest current framing to test is:

> NOVA TAILS is a character/IP system whose distinctive identities can survive across digital and physical adaptations; the first product should be whichever small experience proves that people care about those identities and want to interact with/collect them.

This is a hypothesis, not canon.

## 5. Target audience hypotheses

We should not use one vague audience such as “people who like cute characters.” Initial segments to test separately:

1. **Character collectors / stylized-creature fans** — care about distinctive identities, evolutions and collection.
2. **Light/midcore progression players** — care about team building, progression and satisfying repeatable play.
3. **3D-print hobbyists** — care about printable quality, modularity, color separation and display value.
4. **Maker/creator audience** — interested in design-to-print process and customization.

A person may belong to multiple segments, but tests should tell us which value proposition attracts them.

## 6. Differentiation hypotheses

Not sufficient:
- cute animal characters;
- sci-fi fantasy;
- gacha;
- evolution;
- AI-generated art;
- printable STL by itself.

Potentially stronger combination to test:

**Recognizable evolving creature identities + coherent universe + adaptations designed intentionally for both digital expression and practical physical collectibility.**

The important word is intentionally: a card image and a print should feel like the same identity, not unrelated AI outputs.

## 7. Highest-risk assumptions

### R1 — Character desirability
People who do not know the project can recognize/prefer/remember the characters strongly enough to want another interaction with them.

### R2 — Differentiation
The visual/product concept is distinguishable from the crowded “cute stylized creature/robot” space.

### R3 — Core interaction
If a game is retained, the repeated interaction is enjoyable without relying on gacha/reward scaffolding.

### R4 — Physical desirability and manufacturability
If printing is retained, an original unknown character can be both desirable as an object and reliably printable/assemblable.

### R5 — Cross-output leverage
Maintaining one master identity across 2D/game/print creates more value than complexity.

## 8. Cheapest credible tests

### Test A — Character desirability / identity test — FIRST
Create a small deliberately diverse set (3–5, not 20+) under one visual-quality bar. Show neutral presentation to people outside the project. Measure unaided recognition/recall, preference reasons, perceived distinctiveness and which character they want to see more of.

**Failure signal:** responses are mainly “cute” but people cannot describe/remember distinct identities.

### Test B — Product-concept choice
Present the same character/IP with 3 lightweight propositions: playable collection experience, printable collectible, character/lore content. Measure which action people actually choose (play prototype / download-or-print interest / follow for next character), not only stated liking.

### Test C — Interaction prototype — CONDITIONAL
If game interest survives Test B, prototype the smallest battle/collection interaction with placeholder art. No gacha/economy. Test whether the repeated decision loop is understandable and worth repeating.

### Test D — Physical proof — CONDITIONAL
If physical interest survives Test B, engineer one representative character and perform actual A1-mini slice/print/assembly tests. Record failures before defining manufacturing standards.

## 9. Decision rules

- If characters are not memorable/distinctive → stop scaling roster; revise Visual/Identity system.
- If characters work but game proposition does not → do not force a game; test collectible/content paths.
- If game interaction works → only then deepen combat/progression.
- If print proposition works but manufacturing fails → revise physical adaptation rules, not master identity automatically.
- If no proposition creates behavioral interest → reconsider the product before more worldbuilding.

## 10. What remains deliberately undecided

- mobile vs web/PC as first interactive platform;
- card battler vs another interaction model;
- team size;
- auto/semi-auto/turn-based combat;
- gacha;
- monetization;
- cultivation/evolution implementation;
- launch role of 3D printing;
- final audience segment;
- final name NOVA TAILS.

## 11. Immediate next action

Run **Test A: Character desirability / identity** before deep lore or combat design.

We already have enough conceptual material to design a tiny test set, but existing characters should not all be treated as production canon. The test should deliberately vary silhouette/body archetype/species/signature idea while holding presentation quality approximately constant.
