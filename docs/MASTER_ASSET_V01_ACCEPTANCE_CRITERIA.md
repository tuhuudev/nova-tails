# Master Asset Architecture v0.1 — Acceptance Criteria

Architecture PR may merge when:

- authority direction and canon boundary are unambiguous;
- schema can represent the provisional reference identity without output-specific pollution;
- at least two adapter manifests depend on the same identity revision;
- adapter transformations cannot silently redefine invariants;
- upstream version/staleness behavior is documented;
- AI context rule prevents prompt/output from becoming authority;
- structured fixtures pass schema validation;
- unresolved physical/product evidence is explicitly marked unresolved;
- no experiment character is accidentally promoted to production canon.

Actual cross-output visuals/geometry are **not** required to merge the architecture definition; they are the next proof that tests whether this architecture survives reality.
