# NOVA TAILS — Asset-First Roadmap

**Status:** REVIEW

## Phase 0 — Repository/Governance
Accepted baseline.

## Phase 1 — Product Vision
Character/IP-first is the current strategic direction; output lanes remain hypotheses rather than mandatory products.

## Phase 2 — Identity evidence
Character desirability pilot produced one exploratory participant. Preserve the evidence and its low-confidence boundary; do not fabricate additional participants.

## Phase 3 — Master Asset Architecture
Define L0/L1/L2/L3 authority, identity schema, adapter contracts and dependency/revision rules. **Current branch.**

## Phase 4 — One reference-character proof
Create one real identity instance and stress-test 2D + print adapters. Do not expand roster.

## Phase 5 — Cross-output validation
Check identity continuity, adaptation exceptions, provenance and dependency impact. Revise architecture where the real proof exposes weakness.

## Phase 6 — Scalable pipeline
Only after the proof: introduce validators/context builders/automation that remove demonstrated repetition.

## Phase 7 — Output-lane product experiments
Use the same source identity to test game, physical collectible and content propositions. Evidence determines which lane receives deeper investment.

## Guardrail

Architecture is infrastructure, not proof of demand. Do not use an elegant asset system as justification for mass-producing characters or building an unvalidated game/economy.
