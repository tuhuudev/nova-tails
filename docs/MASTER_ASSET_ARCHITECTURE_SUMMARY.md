# Master Asset Architecture v0.1 — Summary

NOVA TAILS treats the **shared character identity/design system as the production platform**. Game, print, Card/2D and content are adapters that consume the same reviewed identity rather than independently recreating it.

```text
L0 Identity → L1 Master Design → L2 Adapters → L3 Deliverables
                              ↙    ↓    ↓    ↘
                            Game Print 2D  Content
```

The key control is not file reuse but **identity-contract reuse**. Mediums may change implementation while declared invariants remain stable.

v0.1 proves the contract shape with one DRAFT Spirit-derived fixture and two manifests (Card/2D + Print). Actual visuals/geometry are intentionally the next proof.

Architecture acceptance does not imply market validation or production-canon character approval.
