# Master Asset Architecture v0.1 — Executive Summary

NOVA TAILS will develop its character/IP system as a shared asset platform before committing deeply to any one output lane.

## Source hierarchy

```text
L0 Identity/Canon
      ↓
L1 Master Design
      ↓
L2 Medium Adapters
      ↓
L3 Deliverables
```

The source of truth is a contract, not a universal mesh/image.

## Current proof object

`NT-CHAR-001@0.1` is a DRAFT Spirit-derived reference with one identity-critical feature: an incomplete asymmetric broken orbit around a floating central core.

Both the card/2D and print adapters depend on this same revision.

## Why this matters

The system can later generate coherent game, print, card and content assets while allowing each medium to solve its own technical constraints. Upstream identity changes become traceable instead of silently drifting across independent prompts/files.

## What is not proven

- people want a multi-output ecosystem;
- this reference character should ship;
- print geometry is manufacturable;
- game is the right first product;
- automated registry/tooling is necessary.

Those remain separate validation questions.
