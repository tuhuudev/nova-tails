# NOVA TAILS — Asset Authority Rules

1. Character identity is defined upstream, not by the latest render.
2. A polished output is not canon merely because it looks good.
3. Medium adapters own technical compromises, not identity redefinition.
4. Derived exports never outrank their source manifest/design.
5. AI prompts are generated instructions, not authority.
6. Upstream invariant changes require downstream impact review.
7. DRAFT assets may be used for proofs without becoming production canon.
8. Physical manufacturing claims require physical evidence when consequential.
9. Add structure only after real assets reveal the need.
10. Market desirability and technical architecture are separate evidence tracks.
