# Asset Authority Rules

1. L0 character identity owns semantic identity invariants.
2. L1 owns reviewed shared visual definition when such a source exists.
3. L2 adapters own only medium-specific transformations/implementation.
4. L3 deliverables own nothing upstream; they are derived.
5. A downstream need may create an upstream proposal, never an implicit rewrite.
6. Prompts, chat history and generated outputs are not authority.
7. DRAFT structured data is still DRAFT; machine readability does not imply canon.
8. If two sources disagree, resolve at the highest relevant authoritative layer rather than copying the conflict downstream.
