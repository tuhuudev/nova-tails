# NOVA TAILS — Master Design Layer (L1) v0.1

L1 exists between semantic identity and production adapters, but it should contain only shared visual source material that actually benefits multiple outputs.

Potential L1 artifacts when real production requires them:
- approved turnaround;
- proportion/landmark sheet;
- silhouette reference;
- signature-geometry construction guide;
- material-zone map;
- palette tokens;
- high-quality neutral master geometry.

Not every character needs every artifact.

For `NT-CHAR-001@0.1`, L1 is intentionally not instantiated yet because the first controlled 2D proof will help determine which visual references are actually useful. Creating an empty master-asset tree now would violate the architecture's evidence-driven rule.
