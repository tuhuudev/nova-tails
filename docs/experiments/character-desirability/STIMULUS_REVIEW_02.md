# Stimulus Review 02 — Revised Identity Exploration

**Status:** REVIEW  
**Date:** 2026-09-16  
**Experiment:** Character Desirability / Identity v0.1

## Purpose

Review the second visual exploration after applying the v02 silhouette rules. This is internal design evidence only; it is not participant evidence and does not promote any identity to canon.

## Review summary

The revised set materially improves category separation. Wild now reads as a raptor/insectoid machine rather than another fox/wolf quadruped. Scout, Guardian, Spirit and Wild occupy four substantially different body architectures:

- Scout — compact mammalian/agile/grounded, split-tail mass.
- Guardian — broad/heavy/grounded, shell-dominant mass.
- Spirit — floating/vertical, broken-orbit negative space.
- Wild — lean/asymmetric, raptor/insectoid stance with unilateral crescent.

This is sufficient to move from broad topology exploration into controlled stimulus preparation, with remaining refinements below.

## Identity review

### A — Scout — CONDITIONAL PASS

Strengths:
- strong small/agile read;
- forward ears + split rear mass distinguish the silhouette;
- useful familiar-archetype control.

Remaining risk:
- generic fox familiarity can inflate preference/recall.

Requirement for test stimulus:
- split-tail geometry must remain visible in pure silhouette;
- do not interpret high preference alone as proof of original identity strength.

### B — Guardian — CONDITIONAL PASS

Strengths:
- strongest mass contrast;
- low broad posture reads as protector;
- shell is visually dominant.

Remaining risk:
- some silhouettes still read as simply “large armored quadruped.”

Requirement for test stimulus:
- choose the candidate where shell segmentation/closure is most obvious;
- retain shell signature in recall questions.

### C — Spirit — PASS FOR CONTROLLED STIMULUS

Strengths:
- clearly non-grounded topology;
- broken orbit creates useful negative-space signature;
- survives removal of face/species cues better than the other concepts.

Remaining risk:
- generic sci-fi floating-orb association.

Requirement:
- orbit architecture must remain asymmetric/broken rather than a generic perfect halo.

### D — Wild — CONDITIONAL PASS

Strengths:
- category-level overlap with Scout is substantially reduced;
- raptor/insectoid locomotion and unilateral crescent create distinct mass/orientation;
- emotional read remains wary/dangerous without mammalian fox/wolf anatomy.

Remaining risk:
- could drift toward generic sci-fi raptor/mecha creature if the crescent becomes decorative rather than structural.

Requirement:
- select silhouette where unilateral crescent changes overall body balance/negative space;
- avoid relying on red/black color for identity.

## Internal confusion review

At thumbnail/silhouette level the intended descriptions are now meaningfully separable:

| Identity | Expected shape-first description | Category-confusion risk |
| --- | --- | --- |
| Scout | small forward explorer with split-tail geometry | Medium — familiar fox archetype |
| Guardian | broad protector with closing shell | Low–Medium |
| Spirit | floating broken-orbit being | Low |
| Wild | lean asymmetric raptor/insectoid with unilateral crescent | Low–Medium |

**Internal gate:** PASS WITH CONDITIONS.

The set is now good enough to prepare controlled stimuli. It is not yet good enough to use the polished exploration board directly in participant testing because render complexity, color, quotes and environmental presentation would bias preference.

## Controlled stimulus specification

Prepare two separate rounds:

### Round S — silhouette
- one selected silhouette per identity;
- solid black only;
- identical canvas size;
- normalized apparent height/visual mass;
- neutral light background;
- no name, letter, color, icon, quote, lore or environment;
- randomized display order per participant when practical.

### Round N — neutral render
- one neutral 3/4 render per identity;
- same apparent scale and camera treatment;
- same neutral background/lighting quality;
- no environment, quote, lore, faction/class/element labels;
- restrained palette only after silhouette round is complete;
- do not show turnarounds/details before preference/recall questions.

## Pilot before external test

Run a 3–5 person pilot only to validate the procedure/questions. Pilot responses do not count toward the directional sample.

Check:
1. instructions are understood without explanation;
2. exposure/recall timing is workable;
3. questions do not lead participants toward desired vocabulary;
4. no accidental identity labels leak through presentation;
5. response capture distinguishes generic species recall from signature-feature recall.

## Decision rule after pilot

- If participants repeatedly confuse two identities at shape level → return to silhouette design.
- If identities are separable but preference reasons are generic → refine signature/identity, not rendering polish.
- If identity is remembered through specific signature + continued interest → retain as evidence for the next product-risk test.
- Do not choose a flagship/main character from preference ranking alone.
