# Character Desirability Pilot Package v0.1

**Status:** BLOCKED — HUMAN PILOT REQUIRED  
**Date:** 2026-09-16  
**Experiment:** Character Desirability / Identity v0.1

## Purpose

This is the operator-ready package for the 3–5 person procedural pilot. It does not contain market evidence and does not approve any character as canon.

The pilot validates whether the current stimuli and questions can measure shape/signature recognition without leaking intended archetypes or letting rendering polish dominate.

## Required stimuli before P01

Freeze one version of each of these assets before the first participant:

### Round S — silhouette
Four stimuli only:
- Scout: compact forward explorer; split-tail geometry clearly readable.
- Guardian: broad low protector; closing/segmented shell changes the outer silhouette.
- Spirit: floating body/core; asymmetric broken-orbit negative space.
- Wild: lean asymmetric raptor/insectoid; unilateral crescent changes body balance/negative space.

Presentation constraints:
- solid black silhouette;
- identical canvas dimensions;
- neutral light background;
- normalized apparent scale;
- no names, letters, colors, icons, lore, environment or labels.

### Round N — neutral render
One comparable 3/4 render of each same identity:
- same apparent scale;
- same camera family;
- same neutral background and lighting quality;
- restrained palette;
- no environment, quote, lore, class/faction/element labels;
- no turnaround/detail sheet before questions are complete.

If any identity cannot meet these controls, do not start the pilot.

## Operator sequence

1. Assign anonymous participant ID (`P01`–`P05`).
2. Record only necessary coarse context; do not collect unnecessary personal data.
3. Randomize Round S order when practical and record the order.
4. Show Round S without explaining intended archetypes.
5. Ask the Round S questions exactly enough to preserve neutrality; probe only with non-leading prompts such as “What makes you say that?”
6. Remove all stimuli.
7. Run a short unrelated interruption with approximately consistent duration.
8. Run unaided recall before showing any image again.
9. Record signature-specific recall separately from species/category recall.
10. Show Round N only after recall is complete.
11. Ask preference/distinctiveness/familiarity/continued-interest questions.
12. Record verbatim phrases when a participant names an external character/franchise or a memorable feature.
13. Do not redesign stimuli between participants in the same pilot version.

## Question script

### S — silhouette
For each stimulus:
1. What does this shape make you think this character is like?
2. What physical feature do you notice first?
3. Does it remind you of a specific existing character or franchise? If yes, which one and why?

### R — unaided recall
1. How many characters or shapes do you remember?
2. Describe each one without seeing the images.
3. What feature helped you remember each one?
4. Were any two easy to confuse? Which and why?

### N — neutral render
1. Which one would you most like to see again or learn more about? Why?
2. Which one feels most distinct from the others? Why?
3. Which one feels most familiar or derivative? What does it remind you of?
4. If these belonged to one universe, do they feel compatible? Why or why not?
5. Which one would you most want to interact with, collect, play, watch/read about, or own physically? “None” and multiple answers are valid. Why?

Do not mention game, gacha or 3D printing before N5.

## Coding rules

**Exact signature recall:** participant independently describes the intended distinctive geometry/topology, not merely species/archetype.

**Partial signature recall:** participant remembers a distinctive feature but incompletely.

**Generic recall:** participant remembers only category/species/style such as “fox,” “big armored animal,” “floating robot,” or “raptor.”

**Identity-specific preference:** reason refers to a concrete shape, behavior implication, signature feature or memorable identity trait visible in the controlled stimulus.

**Generic preference:** reason is primarily “cute,” “cool,” “strong,” favorite color/species, or rendering polish without identity-specific explanation.

External-IP association is recorded as research evidence only; it is not a legal determination.

## Pilot gate

### PASS PROCEDURE
Proceed to a frozen directional test only if:
- instructions are understood without archetype explanation;
- all four stimuli are distinguishable at the actual display size;
- recall questions work without showing images again;
- observer can reliably separate signature recall from generic category recall;
- neutral-render presentation is comparable enough not to obviously dominate preference;
- no repeated wording problem pushes participants toward project vocabulary.

### REVISE
Revise and run a new pilot version if:
- the same identity pair is repeatedly confused for the same shape reason;
- a required signature disappears at display size;
- participants need labels/explanations to answer;
- presentation quality obviously drives preference;
- coding cannot distinguish signature recall from generic recall;
- the questionnaire itself creates the vocabulary being measured.

A pilot PASS validates the procedure, not character desirability, market demand, originality, legal clearance or product-market fit.

## Evidence boundary

Do not merge pilot observations into the later directional sample. Keep the pilot version, stimulus version and participant IDs traceable. If stimuli change materially after the pilot, increment the stimulus version and treat the later test as a new frozen set.
