# Character Identity Pilot Protocol v0.1

**Status:** REVIEW  
**Purpose:** Validate the experiment procedure before the directional participant test.  
**Pilot size:** 3–5 people. Pilot data is procedural evidence, not market evidence.

## Research question

Can people distinguish and later remember the candidate identities through shape/signature rather than only color, polish or generic species familiarity?

## Stimulus rounds

### Round S — silhouette recognition
Show four normalized silhouette stimuli with no names/colors/text. Randomize order when practical.

For each stimulus ask, without offering vocabulary:
1. What does this shape make you think this character is like?
2. What physical feature do you notice first?
3. Does it remind you of a specific existing character/franchise? If yes, which one and why?

Do not ask “Is this a scout/guardian/spirit/wild?” because that leaks the intended archetype.

### Interruption
Use a short unrelated filler task/conversation before recall. Keep timing approximately consistent across pilot participants; exact timing is not a market metric.

### Round R — unaided recall
Remove stimuli and ask:
1. How many characters/shapes do you remember?
2. Describe each one without seeing the images.
3. What feature helped you remember each one?
4. Were any two easy to confuse? Which and why?

Record whether recall is:
- signature-specific;
- topology/category-level only;
- color/detail dependent (should not apply in silhouette round);
- confused/absent.

### Round N — neutral render preference
Only after silhouette recall, show comparable neutral renders.

Ask:
1. Which one would you most like to see again or learn more about? Why?
2. Which one feels most distinct from the others? Why?
3. Which one feels most familiar/derivative? What does it remind you of?
4. If these belonged to one universe, do they feel compatible? Why/why not?
5. Which one would you most want to interact with, collect, play, watch/read about, or own physically? Allow “none” and multiple answers; ask why.

Do not mention game/gacha/3D printing before question 5.

## Observer coding

For each identity capture:
- silhouette recognized/distinguished: yes/no/unclear;
- unaided recall: yes/no;
- signature recalled: exact/partial/generic/none;
- confusion pair(s);
- external-IP association and stated reason;
- preference reason: identity-specific vs generic cute/cool/strong;
- continued-interest mode: interact / collect / game / story-content / physical / none / other.

## Pilot failure conditions

Revise procedure/stimuli before external testing if any of these occur repeatedly:
- participant needs archetype labels to understand the task;
- two identities are confused for the same shape/category reason;
- a signature feature is invisible at the actual display size;
- question wording causes participants to repeat our vocabulary;
- neutral render quality differs enough to dominate preference;
- participant cannot distinguish “reminds me of X” from “looks copied from X” because the prompt is leading.

## Interpretation guardrails

- 3–5 pilot participants cannot establish desirability or market demand.
- The later 15–25 person sample is directional, not statistically representative.
- Preference ranking alone does not select a flagship.
- Familiarity can increase both preference and recall; code it separately.
- External-IP association is a research signal, not a legal conclusion.
- Negative feedback is useful evidence; do not redesign mid-participant and mix versions in one sample.

## Data handling

Use anonymous participant IDs such as `P01`, `P02`. Do not collect unnecessary personal information. Record only coarse audience-fit context that Product Vision later demonstrates is needed.

Suggested result table:

| Participant | Stimulus | Recall | Signature recall | Confused with | External association | Preference reason | Continued interest |
| --- | --- | --- | --- | --- | --- | --- | --- |
| P01 | A | yes | partial | none | ... | ... | ... |

## Gate after pilot

If procedure is understandable and stimuli remain separable, freeze the stimulus version and run the directional test without changing designs mid-sample. If not, revise and run a new pilot version.
