# Stimulus Review 01 — Character Identity Exploration

**Status:** REVIEW  
**Date:** 2026-09-16  
**Experiment:** Character Desirability / Identity v0.1

## Purpose

Review the first generated four-identity exploration board against the experiment protocol. This is a design review, not participant data and not canon approval.

## Stimulus

A single comparable board was generated from the four contrast-first briefs: Scout, Guardian, Spirit, Wild. The board includes hero renders, silhouette explorations, rough turnarounds, color variants and environmental context.

The generated image itself remains an experiment artifact outside canonical character data. Do not infer exact geometry, names, species, colors or lore from it.

## What worked

### A — Scout
- Reads immediately as small/agile and forward-moving.
- Ear/tail mass gives strong thumbnail readability.
- Visually accessible and likely useful as a control for the familiar cute-creature archetype.

### B — Guardian
- Strong mass contrast against Scout.
- Low, broad stance and shell/armor volume communicate protection before details are read.
- Grounded quadruped body provides useful contrast to floating Spirit.

### C — Spirit
- Strongest structural departure from animal-mecha conventions.
- Floating vertical composition and broken orbital ring remain legible in silhouette.
- Provides an important test of whether NOVA TAILS can support non-animal identity forms.

### D — Wild
- Lean/asymmetric/aggressive read is substantially different from Guardian and Spirit.
- Crescent tail/body arc gives a usable signature direction.
- Emotional read is clear without relying on text.

## Problems discovered

### P1 — Scout and Wild are still too close at the category level
Both remain pointed-ear, tailed, four-legged techno-creatures. Their pose and mass differ, but a participant may remember them as “cute fox” and “dark fox/wolf” rather than two original identities.

**Action:** Before participant testing, push Wild further away from mammalian fox/wolf anatomy. Keep lean/asymmetric/crescent principles but explore a different locomotion/body architecture (e.g. raptor/insectoid/serpentine hybrid) without changing its experimental role.

### P2 — Presentation is too polished for the first recognition test
Hero renders, color variants and environments can bias preference toward rendering quality, color and genre familiarity.

**Action:** Build a silhouette-only stimulus set first. Use identical scale, framing and neutral presentation. Do not expose names, traits, quotes, environment or color during silhouette recognition.

### P3 — Scout is archetypically familiar
Scout is appealing but close to a crowded stylized fox/robot-mascot vocabulary. That makes it useful diagnostically but dangerous as a flagship assumption.

**Action:** Treat Scout as a familiar-archetype control. It cannot become production canon solely because it receives high preference scores; recall must be tied to its specific signature rather than generic fox familiarity.

### P4 — Guardian’s signature is less obvious than its mass
The broad body is memorable, but the intended closing-shell feature is not yet clearly dominant in all silhouettes.

**Action:** Next exploration should exaggerate the shell transformation/closure geometry so participants can describe a specific feature rather than only “big armored animal.”

### P5 — Color variants are premature
Color exploration adds visual richness but is not needed to answer the first experiment question.

**Action:** Freeze palette decisions. Color becomes a second-stage variable only after silhouette/shape contrast passes.

## Review outcome

**Do not run external participant testing on the polished board yet.**

The board successfully validates that the four briefs can produce materially different visual directions, but it also reveals category overlap that the written brief alone did not expose.

### Gate decision

- Scout: KEEP FOR TEST, as familiar-archetype control; refine signature.
- Guardian: KEEP, strengthen closing-shell signature.
- Spirit: KEEP, currently strongest category contrast.
- Wild: REVISE before testing; move away from fox/wolf quadruped anatomy.

## Next stimulus sequence

1. Generate silhouette-only exploration v02.
2. For each identity, select 3 candidate silhouettes using only mass/orientation/signature criteria.
3. Reject candidates with category-level overlap.
4. Run an internal confusion check at thumbnail size.
5. Only then generate one comparable neutral concept render per surviving identity.
6. Pilot the protocol before external testing.

## Canon rule

Nothing in this review promotes a character, visual detail, palette, name, species, faction, element, class or lore to canon. Experiment success only provides evidence for a direction; promotion requires a separate design decision/ADR.
