# Architecture Decision Log v0.1

## Accepted for this PR

- Character/IP-first is the working production architecture direction.
- L0/L1 own shared identity/design authority; adapters consume them.
- One universal binary is explicitly rejected as the meaning of single source of truth.
- Identity invariants and adapter transformations are separately declared.
- Structured identity/adaptation contracts are justified now because one real fixture exists.
- Spirit-derived NT-CHAR-001 is only an architecture fixture.
- 2D + Print is the first cross-output stress test.

## Deferred

- final commercial output lane;
- production character promotion;
- detailed lore/game schemas;
- final DCC/master geometry format;
- asset registry service;
- Git LFS;
- print connector/tolerance standard;
- large-scale automation.

## Evidence boundary

P01 is retained as exploratory `n=1`; it informs risks but does not validate demand or choose a flagship.
