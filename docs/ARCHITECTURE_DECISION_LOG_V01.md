# Master Asset Architecture — Decision Log v0.1

## Accepted for review

- Character/IP-first shared asset platform is the current strategic direction.
- Source of truth is semantic/design authority, not a single universal binary.
- L0/L1/L2/L3 dependency direction is downstream-only by default.
- Adapters may propose upstream changes but cannot silently redefine identity.
- One DRAFT reference character is enough for the first architecture stress test.
- Actual output proofs precede roster scaling.

## Deliberately deferred

- final game technology;
- final DCC/modeling format;
- Git LFS;
- content-addressed storage;
- database/registry service;
- exhaustive world schemas;
- universal manufacturing constants;
- automated prompt/context service;
- CI dependency invalidation.

## Revisit triggers

A deferred decision should be reopened when a real retained asset, repeated workflow, repository-size constraint or production failure makes the choice consequential.
