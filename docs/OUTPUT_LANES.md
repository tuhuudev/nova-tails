# NOVA TAILS — Output Lanes v0.1

Output lanes are optional consumers of the IP asset platform.

Current candidate adapters:
- `card-2d`
- `print`
- `game`
- `content`

An adapter existing in architecture does not obligate the project to ship that product.

A lane may be:
- explored;
- validated;
- paused;
- dropped;
- commercialized later.

Dropping a lane should not require redefining the master character identity unless that lane had incorrectly leaked medium-specific constraints upstream.
