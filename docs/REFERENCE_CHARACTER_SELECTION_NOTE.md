# Reference Character Selection Note

**Status:** DRAFT TEST FIXTURE

For Master Asset Architecture v0.1, use the experiment **Spirit** direction as provisional `NT-CHAR-001` architecture fixture.

Reason: its central-core + broken-orbit topology creates a strong, explicit invariant that can be stressed differently by 2D composition and physical print segmentation. P01 also read it as categorically different, but `n=1` is not the selection basis for production canon.

This selection means only: **use it to test the architecture**.

It does not mean:
- Spirit is a production character;
- it is the flagship;
- it won the desirability experiment;
- its current visual details are canon;
- the project has validated market demand.

If the architecture proof completes, `NT-CHAR-001` may be deprecated as a fixture or promoted only through a separate character review decision.
