# Phase 2 — Architecture Proof Metrics

These are engineering review signals, not market KPIs.

For the reference proof record:
- invariant violations per adaptation;
- number of upstream facts duplicated manually in adapter data;
- number of adapter-specific facts leaking into identity data;
- whether reviewer can trace each output to character revision;
- whether an identity-breaking change identifies affected adapters without searching prose;
- whether second output can be generated from the same context without identity re-description.

Target for v0.1 is qualitative simplicity and traceability, not an arbitrary numeric score.
