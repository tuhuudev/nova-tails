# NT-CHAR-001 — Canon Boundary Example

## Upstream identity fact

> The orbit is incomplete/asymmetric and structurally defines negative space around the central core.

## Valid 2D adaptation

Rotate segments and exaggerate perspective while keeping visible gaps and asymmetric mass.

## Invalid 2D adaptation without upstream review

Draw a perfect luminous halo and claim the broken orbit was only an effect.

## Valid print adaptation

Thicken orbit segments and add hidden supports/connectors while assembled gaps remain visually open.

## Invalid print adaptation without upstream review

Join every segment into a continuous ring because it is easier to manufacture.

This is the practical meaning of “one identity, many adaptations.”
