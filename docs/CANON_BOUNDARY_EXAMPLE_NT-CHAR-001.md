# Canon Boundary Example — NT-CHAR-001

## Upstream identity fact
`broken-orbit` is an identity-critical structural feature.

## Valid Card/2D adaptation
Rotate the orbit for composition and add lighting/VFX while keeping the incomplete asymmetric structural orbit visible.

## Invalid Card/2D drift
Replace the orbit with a perfect glowing halo because it looks cleaner.

## Valid Print adaptation
Split/thicken orbit segments and add hidden support interfaces while preserving incomplete asymmetry and negative space.

## Invalid Print drift
Close the orbit into a complete ring because it prints more easily without requesting upstream identity review.

The medium may solve implementation constraints; it may not silently solve them by changing the character definition.
