# NT-CHAR-001 — Print Adaptation Proof Plan

**Status:** PLANNED / NOT MANUFACTURING-VALIDATED

## Purpose

Test whether the broken-orbit identity can survive conversion into a real printable object without allowing print engineering to silently redefine the master identity.

## Preserve
- dominant central core;
- incomplete asymmetric orbit;
- meaningful negative space;
- non-grounded/floating read as far as a physical support solution allows.

## Allowed engineering moves
- split orbit into printable/assemblable components;
- thicken fragile sections after slicer/physical evidence;
- add hidden stand/support interface;
- key connectors and orient parts for printing;
- simplify micro-detail;
- adjust orbit phase for stability while retaining broken asymmetric read.

## Not allowed without upstream review
- close the orbit into a complete halo;
- remove orbit negative space;
- turn the identity into a grounded quadruped/normal animal;
- replace the structural orbit with painted/VFX-only decoration.

## Evidence sequence

1. create engineering concept from reviewed identity/L1 reference;
2. check intended scale against A1-mini build volume;
3. slice/manifold/support review;
4. identify fragile features and propose—not assume—thickness changes;
5. print representative prototype;
6. assemble and record fit/stability/signature result;
7. only then propose connector/tolerance standards.

No numeric tolerance is specified in this architecture phase.
