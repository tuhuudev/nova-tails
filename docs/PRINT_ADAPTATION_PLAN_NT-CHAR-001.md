# NT-CHAR-001 — Print Adaptation Plan v0.1

**Status:** DRAFT / NOT PHYSICALLY VALIDATED  
**Target:** Bambu Lab A1 mini  
**Known build volume:** 180 × 180 × 180 mm

## Objective

Translate the floating broken-orbit identity into a practical physical collectible without redefining the master identity.

## Identity constraints carried downstream

Must preserve:
- central floating visual focus;
- meaningful negative space around the core;
- incomplete/asymmetric orbit;
- no conventional animal/quadruped anatomy.

## Proposed physical decomposition

Conceptual parts only:
1. central core shell/body;
2. optional face/core insert if color/material separation requires it;
3. orbit segment A;
4. orbit segment B;
5. orbit segment C only if needed to preserve asymmetric rhythm;
6. hidden structural support/display stem;
7. display base.

The visible gap between orbit segments is identity-critical. A hidden support may bridge/load the structure only if it does not visually close the broken orbit.

## Adaptation freedoms

Allowed:
- rotate orbit segments for print orientation;
- thicken fragile orbit cross-sections;
- simplify surface micro-detail;
- use keyed connectors;
- add a base/support system;
- split large geometry to fit build volume;
- adjust display pose while retaining floating read.

Not allowed without upstream review:
- turn broken orbit into a continuous halo/ring;
- attach animal legs/body topology;
- make support geometry the dominant silhouette;
- remove the negative-space relationship around the core.

## No invented manufacturing constants

v0.1 intentionally does not canonize:
- connector clearance;
- peg diameter;
- minimum wall thickness;
- minimum feature size;
- support angle rules.

Those values depend on actual geometry/material/nozzle/settings and require calibration/physical tests before becoming NOVA TAILS standards.

## First physical test when geometry exists

1. slice every part for A1 mini;
2. confirm fit/build orientation;
3. inspect fragile orbit sections;
4. print a connector/section calibration if required;
5. print full prototype;
6. assemble without destructive fitting;
7. photograph assembled silhouette from primary views;
8. compare against master invariants;
9. record failures and only then revise manufacturing rules.

## Architecture question this adapter tests

Can manufacturability force significant geometry changes while the upstream identity remains stable and reviewable?
